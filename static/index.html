NTP server

Aplikace se přes UDP port 123 dotáže zadaného NTP serveru, změří odchylku a přizpůsobí jí své logy, časové rozvrhy a časové limity. Synchronizace se opakuje automaticky.

Načítám stav synchronizace…

Časové pásmo: Europe/Prague (automatické přepínání letního a zimního času).

Z bezpečnostních důvodů aplikace nemění systémové hodiny hostitele ani Dockeru. NTP odchylka se používá pouze uvnitř aplikace; synchronizace celého serveru se případně nastavuje v jeho operačním systému.
